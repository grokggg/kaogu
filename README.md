# chinese-material-culture-agent
中国历史物质文明复原研究智能体

## 项目简介

本项目是一个基于学术规范的中国历史物质文明复原研究工具，目标是依据可验证的一手考古材料和文献，对历代服饰、建筑、饮食、交通、军事、礼乐等物质文化进行严谨的学术复原，杜绝历史幻想和艺术化臆测。

## 核心原则

- **可溯源性高于一切**：所有视觉细节必须有明确来源
- **未知优于臆测**：宁可标注"未知"，不可编造细节
- **严格分层**：事实、推测、艺术化表现必须明确区分
- **年代锁定**：所有复原必须锁定到具体帝王时期，禁止使用宽泛朝代名
- **双轨验证**：考古实物与文献记载互证，优先采信出土实物

## 使用方法

### 1. 安装依赖
```bash
pip install -r requirements.txt --break-system-packages
```

### 2. 生成研究任务（标准模式，默认）
```bash
python main.py \
  --dynasty "西汉" \
  --period "武帝时期" \
  --object "贵族女性日常服饰" \
  --identity "贵族女性" \
  --scene "日常起居"
```

### 3. 生成研究任务（增强模式，启用通用模板引擎）
```bash
python main.py \
  --dynasty "西汉" \
  --period "武帝时期" \
  --object "贵族女性日常服饰" \
  --identity "贵族女性" \
  --scene "日常起居" \
  --enable-universal
```

增强模式会动态加载对应朝代的参数校验规则（度量衡、建筑规范、服饰禁忌、地图精度等），附加在原系统提示词之后作为补充校验层，不修改原提示词内容。

运行后会在 `outputs/tasks/` 目录下生成任务文件，将任务文件内容提交给Trae即可执行完整研究流程。增强模式下还会在 `outputs/audit/` 目录生成审计日志。

### 4. 研究输出规范

每份研究报告必须包含以下10个章节：
1. 研究对象
2. 文献材料摘要
3. 单件复原卡（每件文物逐件输出）
4. 事实层复原
5. 推论层分析
6. 视觉复原建议
7. 依据溯源
8. 可信度评级
9. 材料冲突
10. 材料覆盖范围声明（含补全路径）

## 资料来源等级

| 等级 | 来源类型 | 可信度 |
|------|---------|--------|
| 一级 | 墓葬发掘报告、出土文物报告、文物图录、博物馆官方资料 | 高 |
| 二级 | CSSCI期刊、北大核心期刊（《考古》《文物》《考古学报》优先） | 中高 |
| 三级 | 正史（舆服志、礼仪志等优先）、典章制度文献 | 中 |
| 四级 | 墓室壁画、石窟壁画、陶俑、传世绘画 | 中低 |

**严禁使用**：百度百科、维基百科、知乎、微信公众号、个人博客、古装影视剧、游戏设定、AI生成内容。

## 注意事项

1. 研究前必须确认：朝代、具体时期、复原对象、身份阶层、使用场景五项参数齐全
2. 必须先联网检索，禁止直接凭内部知识输出复原结论
3. 所有推论必须用【推测】标记，禁止混入事实层
4. 材料冲突时必须列出所有版本，不做调和，按优先级采信
5. 每份报告最后必须明确说明材料覆盖范围和补全路径
